About

My background is in data science and digital marketing. Day to day, I work with data, spreadsheets, and performance reporting in the public health sector in West Java, Indonesia — work that demands numbers that reconcile down to the last cell and documents that can be accounted for.

Outside of that, I like building small software as an answer to concrete problems: a smartwatch that can't be synced from a laptop, a PDF that's hard to download from a government server, an official letter that takes opening a whole website just to check. Most of my projects are open source and deliberately lightweight — many are pure HTML, CSS, and vanilla JavaScript, with no framework and no build step.

Kawi Dictionary — Web Scraping

A Python scraping project that harvests the Kawi–Indonesian dictionary (Wojowasito, 1977) from sastra.org. It collects the entry pages, parses the definition lists with BeautifulSoup, cleans the raw HTML with regular expressions, and exports the result as a structured, formatted dictionary file.

  • Python
  • BeautifulSoup
  • Requests
  • Regex
  • Jupyter

Previu

A small, fast image and PDF viewer for Windows, in the spirit of macOS Preview. Built with Tauri 2 on the WebView2 runtime that ships with Windows, so the app is a few megabytes rather than a few hundred. Features a PDF thumbnail sidebar, text search, presentation mode, and basic image editing.

  • TypeScript
  • Tauri 2
  • Rust
  • pdf.js

ADVAN SW — Web Bluetooth

The result of reverse engineering the BLE protocol of the ADVAN SW smartwatch (Da Fit / CRREPA family), turned into a Web Bluetooth client: connect and handshake, sync the time, read device info, and switch built-in watch faces — all from the browser, without the companion app.

  • Vanilla JavaScript
  • Web Bluetooth API

PDF Downloader

An ultra-lightweight website (under 20 KB, pure vanilla) for downloading PDFs from a link. It has a progress bar and a staged CORS fallback — direct fetch, then proxies, then opening a new tab — because many document servers don't allow cross-origin downloads.
