Tentang

Latar belakang saya di data science dan digital marketing. Sehari-hari saya berkutat dengan data, spreadsheet, dan pelaporan kinerja di lingkungan kesehatan provinsi Jawa Barat — pekerjaan yang menuntut angka yang cocok sampai ke sel terakhir dan dokumen yang bisa dipertanggungjawabkan.

Di luar itu saya suka membangun perangkat lunak kecil sebagai jawaban atas masalah konkret: jam tangan yang tidak bisa disinkronkan dari laptop, PDF yang sulit diunduh dari server pemerintah, sampai surat elektronik yang pengecekannya harus membuka situs dulu. Sebagian besar proyek saya open source dan sengaja dibuat ringan — banyak yang murni HTML, CSS, dan JavaScript vanilla tanpa framework dan tanpa build step.

Prediksi Hilal

Aplikasi web untuk menghitung prediksi visibilitas hilal di seluruh dunia: ketinggian bulan, elongasi, dan umur bulan tepat saat matahari terbenam, lengkap dengan peta interaktif dan penilaian kriteria MABIMS dan Wujudul Hilal.

  • JavaScript
  • Astronomy Engine
  • Leaflet / OpenStreetMap

Finance Tracker — Buku Kas

Tracker keuangan pribadi yang dicatat lewat bot Telegram dengan parsing AI Gemini, datanya tersimpan di Google Sheets. Dashboard web menyediakan ringkasan bulanan, grafik kategori dan tren, analisis AI, serta saldo awal yang terbawa otomatis antar-bulan.

  • Next.js
  • Google Sheets
  • Gemini AI
  • Telegram Bot

Previu

Penampil gambar dan PDF untuk Windows yang kecil dan cepat, terinspirasi Preview di macOS. Dibangun dengan Tauri 2 di atas WebView2 bawaan Windows sehingga ukurannya hanya beberapa megabyte. Mendukung sidebar thumbnail PDF, pencarian teks, mode presentasi, dan pengeditan gambar dasar.

  • TypeScript
  • Tauri 2
  • Rust
  • pdf.js

Cell Architecture Studio

Galeri arsitektur sel 3D interaktif untuk pembelajaran biologi: tujuh jenis sel yang bisa dijelajahi, panel detail organel, mode perbandingan, dan panel AI Tutor. Dirender real-time dengan model GLB dan geometri prosedural sebagai fallback.

  • React
  • TypeScript
  • Three.js
  • Vite

ADVAN SW — Web Bluetooth

Hasil reverse engineering protokol BLE smartwatch ADVAN SW (keluarga Da Fit / CRREPA) yang diwujudkan jadi klien Web Bluetooth: koneksi dan handshake, sinkronisasi jam, info perangkat, dan ganti watchface bawaan — semua dari browser, tanpa aplikasi bawaan.

  • JavaScript Vanilla
  • Web Bluetooth API
  • Reverse Engineering

PDF Downloader

Website super ringan (di bawah 20 KB, murni vanilla) untuk mengunduh PDF dari link. Dilengkapi progress bar dan fallback CORS bertahap — fetch langsung, lalu proxy, lalu buka tab baru — karena banyak server dokumen tidak mengizinkan unduhan lintas domain.

Cek Surat SIDEBAR

Ekstensi Chrome mungil (Manifest V3, tanpa dependensi) untuk mengecek surat di SIDEBAR — Sistem Informasi Dokumen Elektronik Jawa Barat. Cukup masukkan 10 digit kode surat, dokumennya langsung terbuka.

WhisperType Windows

Aplikasi speech-to-text untuk Windows berbasis model Whisper. Hasil transkripsi dikirim langsung ke aplikasi yang sedang aktif — Notepad, Word, atau apa pun — dengan pilihan sumber mikrofon atau loopback, model, dan bahasa termasuk Bahasa Indonesia.
